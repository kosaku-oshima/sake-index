# sake-index
sake-index は、日本酒の記録・検索・振り返りを行う個人用Webアプリです。  
飲んだ日本酒の情報を自分で蓄積し、あとから見返しやすくすることを目的として作成しました。

酒名や飲んだ日付だけでなく、味の印象、タグ、お気に入り度、写真なども記録できます。  
一覧表示、検索、詳細確認、編集、CSV出力までブラウザ上で行えます。

---

## 作った目的

日本酒を飲んだときに「おいしかった」「また飲みたい」と思っても、あとで名前や印象を思い出せなくなることがありました。  
そこで、自分用に日本酒の記録を残し、検索や振り返りができるアプリを作ろうと考えました。

また、このアプリは HTML / CSS / JavaScript を学びながら作成しており、  
個人開発を通して画面設計・データ保存・検索・CSV出力などの基礎を学ぶことも目的としています。

## データ保存について

このアプリのデータは、ブラウザ内の IndexedDB に保存されます。  
そのため、以下の点に注意してください。

- データは同じ端末・同じブラウザでのみ利用できます
- 別の端末や別のブラウザには自動では引き継がれません
- ブラウザの保存データを削除すると、記録が消える可能性があります

必要に応じて CSV 出力を行い、バックアップとして保存することを想定しています。

## 使い方

1. 新規登録画面で日本酒の情報を入力する
2. 一覧画面で登録済みデータを確認する
3. 検索画面で条件を指定して絞り込む
4. 詳細画面で内容を確認し、必要に応じて編集・削除する
5. CSV出力画面から記録をエクスポートする

---

## 工夫した点

- 検索条件を保持したまま画面遷移できるようにした
- 一覧・検索・登録・詳細・出力の役割を画面ごとに分けた
- 共通処理を分離し、コードの見通しをよくした
- CSV出力時に、数値だけでなくラベルも出力できるようにした
- 画像プレビューを表示し、不要な Object URL を解放するようにした
- 個人利用を想定し、操作が分かりやすいシンプルな構成にした
